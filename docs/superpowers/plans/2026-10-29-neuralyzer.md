# Neuralyzer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A native macOS app that scans the disk, groups reclaimable space by type, and cleans what the user selects, shipped as a notarized DMG from a public GitHub repo.

**Architecture:** All scanning, safety, and cleaning logic lives in the Swift package `NeuralyzerKit` (no UI, fully unit tested against a fake home directory). The app target `Neuralyzer` (SwiftUI, generated by XcodeGen from `project.yml`) holds only views and one observable store that calls the kit.

**Tech Stack:** Swift 6.4, SwiftUI, Foundation, XcodeGen, Xcode 27.1, `xcrun simctl`, `notarytool`. No third-party packages.

**Spec:** `docs/superpowers/specs/2026-10-29-neuralyzer-design.md`

## Global Constraints

- macOS 15 minimum. Not sandboxed. Hardened runtime on.
- Zero third-party dependencies. No network calls, analytics, updater, background agent, or menu bar item.
- UI shows only names and sizes: no subtext, no dot menus, no badges, no counts, no charts.
- System font only, SF Symbols only.
- No em dashes in code, comments, commits, docs, or UI strings.
- Conventional commits (`feat(scan): ...`), one branch per change, never commit to `main`.
- Commits authored as `shivvyas2 <shivvyas0209@gmail.com>`, no co-author trailer.
- Rebuildable items are deleted permanently; personal items go to the Trash via `FileManager.trashItem`. Trash items are deleted permanently and never preselected.
- Nothing outside the category roots is ever deleted; symlinks that leave a root are rejected.
- Never touch in `~/.claude`: `settings*.json`, `CLAUDE.md`, `memory`, `skills`, `agents`, `commands`, credentials (`.credentials.json`).
- Sizes are allocated sizes (`totalFileAllocatedSizeKey`).
- Signing identity `Developer ID Application: Shiv Vyas (Z42YU5W6WY)`, notary keychain profile `notary`.

## Review Focus

- A path that is a symlink pointing outside its root (for example `~/Library/Caches/foo -> ~/Documents`): must be refused, not followed. Test in Task 2.
- A file that disappears between scan and clean: clean skips it and continues, no crash, log records `skipped`. Test in Task 6.
- A Claude project folder containing `memory/`: cleaning that row deletes only `*.jsonl` and UUID folders, `memory/` survives. Test in Task 4.
- Permission denied on a subfolder during sizing: that subfolder counts as 0 and the scan continues. Test in Task 3.
- `simctl` missing (no Xcode installed): Simulators category is empty, no error surfaced. Test in Task 5.

### Task 6: Cleaner

**Files:**
- Create: `Cleaner.swift`
- Test: `CleanerTests.swift`

**Interfaces:**
- Consumes: `Item`, `Action`, `SafetyGuard`, `CommandRunner`.
- Produces: `struct CleanReport: Sendable { freed: Int64; trashed: Int64; failures: [String] }` and `actor Cleaner { init(env: ScanEnvironment, log: URL = home/Library/Logs/Neuralyzer/clean.log); func clean(_ items: [Item]) async -> CleanReport; func emptyTrash() async -> Int64 }`.

Behavior: for each item, check `SafetyGuard.allows(item.url, root: item.root!)`; items with a nil root must be simctl actions, anything else is refused. `.delete` uses `FileManager.removeItem`; `.trash` uses `trashItem`; simctl actions run `xcrun simctl delete <udid>` / `xcrun simctl runtime delete <id>`; `.deleteContents(keep:)` removes children matching `*.jsonl` or a UUID name (`UUID(uuidString:) != nil`) and never anything in `keep`. Missing files are logged `skipped`, not failures. Each item appends one line: ISO8601 time, tab, action, tab, bytes, tab, path or id.
